metzler.media.srtp module

SDES-SRTP (RFC 3711, AES_CM_128_HMAC_SHA1_80) for the provider media leg.

AES comes from the optional cryptography package; it is imported lazily so the simulator still runs on a bare Python install (plain RTP then).

class metzler.media.srtp.Srtp(master_key, master_salt)[source]

Bases: object

One direction of an RFC 3711 SRTP stream, suite AES_CM_128_HMAC_SHA1_80 (the SDES default Linphone accepts). Key-derivation rate 0, no MKI. protect(): RTP -> SRTP for sending; unprotect(): SRTP -> RTP or None if the auth tag fails. RTCP is not protected (the bridge sends none).
