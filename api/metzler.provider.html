metzler.provider module

Standard-SIP trunk to a hosted provider (sip.linphone.org) or a PBX (Asterisk).

class metzler.provider.FritzTrunk(st, o)[source]

Bases: SipProvider

A second SIP account on the same socket: –fritz makes the station REGISTER as an IP phone at a Fritz!Box. Inbound fritz calls bridge to –inbound-target like provider app calls. Every bridged call ALSO rings –fritz-call-button in parallel with the provider app (first answer wins).

The racing leg keeps its own state in call.fritz_leg - the call’s prov_* fields belong to the provider leg while both race; the winner gets promoted into them.

class metzler.provider.SipProvider(st, o)[source]

Bases: object

Standard-SIP trunk to a hosted provider (e.g. sip.linphone.org).

Everything the public-SIP side needs lives here so the station only ever delegates: REGISTER (digest auth, NAT learn via the echoed Via), one outbound INVITE leg per bridged Call, and ACK/CANCEL/BYE for that leg.

Packet flow:
station listener -> is_reg_response() -> reg_queue (REGISTER replies)

-> calls[Call-ID] -> handle_response() (INVITE replies)

on_invite bridge -> invite(call) (offer built by offer_sdp()) provider 200 OK -> station.provider_answered() -> ack() teardown -> cancel() / bye()

The provider object sends on the station’s UDP socket (shared source port) via the st back-reference; it owns no sockets of its own.
