metzler.station package

The simulated indoor station (see station.station.IndoorStation).

class metzler.station.IndoorStation(o)[source]

Bases: RegistrationMixin, ProviderBridgeMixin, HaAnswerMixin, LocalAnswerMixin, OutboundCallMixin, InboundCallMixin, TeardownMixin, StationCore

A Hikvision/Metzler indoor extension (VTH) on the intercom LAN.

StationCore socket, RTSP server, receive loop, request routing, run/shutdown RegistrationMixin REGISTER + <regXML> at the registrar, MESSAGE heartbeat ProviderBridgeMixin incoming intercom/door INVITE -> SIP provider leg HaAnswerMixin ha_mode: parked calls answered/ended programmatically (vdm10-ha) LocalAnswerMixin local headset mode (answer on this machine) OutboundCallMixin –call: dial another station (direct or via registrar) InboundCallMixin inbound SIP app call -> –inbound-target on the intercom TeardownMixin CANCEL/BYE from either leg
