Binary bulk

  • V1 hicore 7.7 MB, ~15.4k indexed functions.

  • V2 hicore 12.7 MB, 25,382 indexed records (23,963 .text functions, VDM10_2.0/README.md coverage) — growth is mostly statically-linked libraries: openssl-1.1.1v (source-path literals), curl, sqlite, srt, freetype, libjpeg, libpng, libnl, stlport (C++ stdlib), minigui, hostap-wpa-supplicant, si44xx, cjson, ezviz_cmarkup, hisilicon (VDM10_2.0/human_readable/libraries/).

  • New shared libs in trees/misc/ (only_new, extraction): libbsp_data_encrypt, libssp, libhwsdk, libcam_hal, libddm, libqrencode, libnl-3, libnl-genl-3, libsafefunc, libboundscheck (memory-safe helpers used throughout: memset_s/memcpy_s calls are new-idiom), log4j, dspProc, cam_default.xml (/etc/cam_iq/ path literal).

  • libeXosip2.so/libosip2.so/libosipparser2.so still ship (changed, not removed) — although osip/eXosip are absent from the new GPL list: V1 ships trees/app/gpl/Open_Source_Software_Licenses.cfg; V2 ships _NEU.cfg + _STD.cfg selected at runtime (gui_gpl_refresh_page @0x005581fc; .cfg contents not retained — extraction-note claim).
