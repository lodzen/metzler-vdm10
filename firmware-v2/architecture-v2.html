V2 architecture — how the SIP stack differs structurally

V2.2.100 replaces the v1 C net/sipServer registrar (own parser, stateless replies, strstr body scraping) with a C++ sipsvrLib — an embedded service library of service_sip_t objects threaded onto worker pools, fronted by a sipDevSDK_* callback API. The eXosip client leg (:5060) is kept and extended. Sources: VDM10_2.0/human_readable/sip/server/ (raw: decompiled/.._.._sipsvr_service_sip.cpp.c, .._.._sipsvr_device.cpp.c, .._.._sipsvr_application.cpp.c, net_sipServer_sipsvr.c.c).

2. sipDevSDK callback table & API

sip_start_server_control_thread @0x0011c0c4 installs a 6-word callback block and a 0x24 config block into sipsvr_service_start_wrapper @0x0021af18 → sip_application_initialize. The SDK-facing API surface (self-identified sipDevSDK_* names) lives in sdk_callbacks.c:

get_local_devtype @0x00224870, is_dev_maindoor @0x002249e8, get_Manager_center @0x00224c78, get_dev_LongNum @0x00224fc0, get_Room_LongNum @0x002252c0, get_register_list @0x00225490, get_reply_time @0x00225608, get_reg_sip_password @0x00225828, get_reg_sip_random @0x00225950, get_reg_sip_key @0x00225a34, save_reg_sip_key @0x00225b84, send_register_to_dev @0x00225d14, send_authentication_to_dev @0x002260a8, sipsvr_status_to_dev @0x002263cc, cb_get_reg_password @0x0011a058, cb_get_runtime_info @0x0011a2ac (selector 0–7: own num / dev kind / registrar ip / room addr / ext list / numbering / time-DST / cli flag), cb_recv_sipsvr_msg @0x0011bb7c. The sipsvrLib never touches the cfg blob or DB directly — it calls back through these.

4. Client side — what stayed

eXosip leg: cli_ua_task @0x00143340 (:5060, HKVS/2.0.0 UA) + cli_regist_task/cli_heartbeat_task/cli_send_msg_v2 — MESSAGEs now go to :5065 with digest auth and a response-flag wait (vs v1 fire-and-forget :5065/:5060 unauthenticated). SIP2.0 additions vs v1: <random> key machinery (registration_keys.c), a=version: SDP tag + INVITE digest, fast_regist mq, v2 XML (*_v2 builders/parsers in sip/xml_proc.c).

  • Presence (not analyzed): smartlock/ (client_api/protocol/radio/ packet_codec/dispatch_thread), misc/event_zigbee_rex_zigbee_application.c, ONVIF-adjacent code in misc//net/ — unverified depth.
