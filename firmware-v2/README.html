Isolation

All V2.2.100 evidence lives under ../../VDM10_2.0/: human_readable/ (1,909 named .c reading-view files), decompiled/ (raw Ghidra dumps), names/*.tsv, function_index.tsv, analysis/. The saved Ghidra project is ../../ghidra_proj_v2/hicore_v2.gpr (program /hicore, ARM v8). The authoritative registration-regression analysis is ../../VDM10_2.0/analysis/registration.md; where these docs differ from it, that report wins.

The V2.0.24 material is untouched: ../../vdm10_1.0/ + ghidra_proj/hicore_proj

  • ../firmware/ remain the reference for the old stack, and are cited here only for comparison. The fw2_extracted/ rootfs tree was removed; re-derive it via the cramfs carve at .dav offset 0x6c (3DES key 2102034d561311120102034d561011120102034d5612111d) — see VDM10_2.0/README.md for the reproduce recipe and coverage caveats.

The simulator’s own wire-level description of the same protocols is in ../protocol.md.
